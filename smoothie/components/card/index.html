Slot Guide

Card Slots

  • header — Card title or heading (appears in top-left with flex layout)
  • close — Optional close button or icon (appears in top-right)
  • description — Text description or supporting content
  • input — Form input, text field, or custom input element
  • actions — Action buttons (footer area)
