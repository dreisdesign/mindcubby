2. Components Toast
Note: Toast is a singleton component placed once near the body. Use the show() method to display notifications from anywhere in your app.

Variants

Show Primary
Show Secondary
Show Destructive

With Action Button

Show with Undo

Usage Example

const toast = document.querySelector('labs-toast');

// Basic notification
toast.show('Operation completed!');

// With action button
toast.show('Item deleted', {
    actionText: 'Undo',
    duration: 5000,
    onAction: () => console.log('Undo clicked')
});

// Different variants
toast.show('Error occurred', { 
    variant: 'destructive' 
});
