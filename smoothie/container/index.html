Container Component

Responsive width container with desktop and mobile padding

Container Variants

Resize your browser to see responsive behavior. On mobile (<640px), all containers use 100% width with 1rem padding.

Small (400px max-width)

Small Container
Desktop: max-width 400px, padding 2rem
Mobile: 100vw, padding 1rem

Medium (600px max-width)

Medium Container
Desktop: max-width 600px, padding 2rem (default)
Mobile: 100vw, padding 1rem

Large (800px max-width)

Large Container
Desktop: max-width 800px, padding 2rem
Mobile: 100vw, padding 1rem

Fill (100vw full viewport)

Fill Container
Desktop & Mobile: 100vw width, 100vh height, flexbox layout
Use case: Full-page layouts, hero sections
Responsive Behavior Mobile breakpoint: 640px (configurable via --container-mobile-breakpoint CSS variable)

Usage Example

<labs-container medium>
  <h1>Centered Content</h1>
  <p>This content is centered with max-width 600px</p>
</labs-container>
