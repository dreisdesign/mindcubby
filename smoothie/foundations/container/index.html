About This Component

<labs-container> is a responsive width container component that centers content and provides consistent max-width constraints across different screen sizes. Perfect for building responsive layouts that work on all devices.

  • Responsive sizing: Small (400px), Medium (600px), Large (800px), Fill (100vw)
  • Mobile-first approach: Switches to 100vw with padding below 640px
  • Automatic centering: Content always centered horizontally
  • Consistent padding: Respects design system spacing tokens

Responsive Breakdown

How Container Sizes Work

  • Small (400px): Narrow content layouts, blog posts
  • Medium (600px): Standard UI layouts, forms, cards (default)
  • Large (800px): Content-rich pages, dashboards
  • Fill (100vw): Full-page layouts, modal backgrounds

Mobile Behavior

At breakpoint 640px and below, all containers switch to 100vw width with 1rem padding. Try resizing your browser to see this in action!
