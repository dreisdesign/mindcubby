Smoothie Foundations Footer Layout

Overview

labs-footer-layout is a structural foundation component that manages a full-page layout pattern: header bar at top, scrollable content in the middle, and sticky footer at the bottom.

Use Cases

  • App dashboards (Tracker, Analytics)
  • Content-heavy pages with persistent controls
  • Mobile-friendly layouts with fixed header and footer
  • Any app needing header + scrollable content + sticky actions

Structure

The component uses three named slots to organize content:

slot="header"
Fixed at top. Use for control bars, navigation, theme toggles. Does not scroll.
slot="content"
Scrollable middle area. Fills available space. Use for main page content, grids, lists.
slot="footer"
Sticky at bottom of viewport. Use for persistent controls, settings, footer info.

Key Features

  • No dual scrollbars — Uses flexbox with proper min-height constraints
  • Sticky footer — Always visible, content scrolls behind it
  • Full viewport — Takes 100vh height by default
  • Semantic slots — Clear content organization

Implementation

Wrap your page structure with named slots:

<labs-footer-layout>
  <labs-container slot="header">
    <!-- Control bar, theme toggles -->
  </labs-container>

  <labs-container slot="content">
    <!-- Main page content -->
  </labs-container>

  <labs-footer slot="footer">
    <!-- Footer content -->
  </labs-footer>
</labs-footer-layout>
