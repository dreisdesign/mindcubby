Usage Guide

Use Primary For

Main user actions like Save, Submit, Create, Continue. Only one primary button per screen when possible.

Use Secondary For

Alternate actions, cancellation, or less important actions like Cancel, Skip, Learn More.

Use Destructive For

Irreversible or critical actions like Delete, Remove, Close Account. Use sparingly.

Size Selection

Large for page-level actions, Medium for component-level actions, Small for compact contexts like tables.

Icons with Buttons

Icons clarify intent and improve scannability. Icon-only buttons must have aria-label for accessibility.

Disabled State

Use when action is unavailable. Disabled buttons should not show tooltips or hover states.
