Pattern Guidelines

Button Row (Horizontal)

Use for action pairs: primary + secondary, or destructive + secondary. Space buttons with `gap: 1rem`. Keep to 2-3 buttons max.

Button Stack (Vertical)

Use for lists of options (settings, menu items). Make buttons full-width with `width: 100%`. Space with `gap: 0.75rem`. Common in overlays and cards.

Icon-Only Buttons

Always include `aria-label` for accessibility. Use in headers, toolbars, and footers where space is limited. Use secondary variant for neutral actions, primary for main CTA.

Spacing & Layout

Horizontal row: `display: flex; gap: 1rem;` | Vertical stack: `display: flex; flex-direction: column; gap: 0.75rem; width: 100%;` Match button sizing to context: medium in footers, large in dialogs.
