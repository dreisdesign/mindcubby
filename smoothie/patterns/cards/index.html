Pattern Guidelines

Grid Layout (Products, Cards, Content)

Use `grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))` for responsive multi-column cards. Gap depends on context: 1.5rem for spacious layouts, 1rem for compact.

Horizontal Row (Comparison, Status)

Use `display: flex; gap: 1.5rem; flex-wrap: wrap;` for side-by-side cards. Add `flex: 1;` to cards for equal width distribution.

Stacked/List (Activity, Tasks, Items)

Use `display: flex; flex-direction: column; gap: 1rem;` for vertical card stacks. Common in inboxes, task lists, and feeds.

Dialog/Modal (Confirmation, Onboarding)

Wrap cards in a modal overlay (labs-overlay). Use `max-width: 400-500px` for focused dialogs. Center horizontally with `margin: 0 auto;`
