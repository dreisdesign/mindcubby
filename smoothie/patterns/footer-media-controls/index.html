Best Practices

  • Use fixed footer to keep player accessible while scrolling
  • Show thumbnail, title, and artist/creator in media info section
  • Center primary playback controls (play, pause, next)
  • Place secondary controls (volume, speed) on the right
  • Use consistent icon sizes and spacing
  • Provide compact view for narrow screens
  • Add keyboard shortcuts for accessibility
