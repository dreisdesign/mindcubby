Toast Notifications

Non-blocking feedback messages that appear temporarily and auto-dismiss. Use toasts for notifications, confirmations, and reversible actions (undo).

Basic Toasts

Success Message

Confirm a completed action with automatic dismiss.

Show Success Toast
toast.show('File saved')

Error Message

Alert the user to an error that occurred.

Show Error Toast
toast.show('Failed to load')

Info Message

Provide helpful information or context.

Show Info Toast
toast.show('Loading...')

Toasts with Actions

Undo Action

Let users reverse their last action with an undo button.

Show Undo Toast
toast.show('Item archived', {
actionText: 'Undo',
duration: 5000
})

Confirm Action

Provide an action button for confirmation or next step.

Show Confirm Toast
toast.show('New message', {
actionText: 'View',
variant: 'primary'
})

Destructive Action

Use for critical actions that need clear visual hierarchy.

Show Delete Toast
toast.show('Delete account?', {
actionText: 'Confirm',
variant: 'destructive'
})

Usage Patterns

When to Use Toasts

• Non-blocking notifications
• Temporary feedback (auto-dismisses)
• Reversible actions (with Undo)
• Success/error confirmations
• Brief messages (avoid long text)

When NOT to Use Toasts

• Critical alerts that need user confirmation
• Important information that shouldn't be missed
• Long-form content or instructions
• When accessibility feedback is essential

Best Practice: Toasts work best for reversible actions like archive, delete, or undo. Avoid using them for critical information users must remember.
