Theme & Appearance System
How It Works

Smoothie uses a two-dimensional theming system:

  • Theme: Controls the primary color palette (Vanilla, Blueberry, Strawberry)
  • Appearance: Controls light/dark mode for better accessibility

Use the controls in the top right to cycle through themes and toggle between light/dark modes. All color tokens automatically adjust based on your selection.

Technical Implementation

Storage Keys:

  • smoothie-theme: Stores theme (vanilla, blueberry, strawberry)
  • smoothie-appearance: Stores appearance (light, dark)

CSS Variables:

All color tokens are defined in flavors.css as semantic variables:

  • --color-primary (primary action color)
  • --color-surface (card/container background)
  • --color-on-surface (text on surfaces)
  • ...and 20+ more semantic tokens
